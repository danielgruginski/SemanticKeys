# **Configuration & Attributes**

## **Semantic Keys Settings**

The package relies on a singleton `ScriptableObject` to store project-wide settings. This asset is automatically created the first time you interact with the system.

**Location:** `Assets/Data/SemanticKeys/SemanticKeysSettings.asset`

| Setting | Default | Description |
| ----- | ----- | ----- |
| **Domain Creation Path** | `Assets/Data/SemanticKeys` | The folder where new `KeyDomain` assets will be created when you click "+ Create New Domain" in the Inspector dropdown. |
| **Generated Code Path** | `Assets/Scripts/AutoGenerated` | The folder where the static C\# classes (e.g., `Stats.cs`) will be written. |
| **Generated Namespace** | `Game.Constants` | The C\# namespace used for the generated static classes. Change this if you want to organize your keys differently (e.g., `MyGame.Keys`). |

**Note:** If you move the `SemanticKeysSettings` asset to a different folder, the package will still find it. However, do not duplicate it; the system expects only one settings file.

## **\[SemanticKeyFilter\] Attribute**

The `[SemanticKeyFilter]` attribute is used to restrict a `SemanticKey` field in the Inspector to a specific Domain.

### **Usage**

    using UnityEngine;  
    using SemanticKeys;
    
    public class InventoryItem : MonoBehaviour  
    {  
        // Shows keys from Stats, Audio, AI, etc.  
        public SemanticKey Category;
    
        // Only shows keys from the "ItemCategories" domain  
        \[SemanticKeyFilter("ItemCategories")\]  
        public SemanticKey ItemType;  
    }

### **Critical Warning**

The filter matches the **Internal Domain Name**, not the file name.

* If you rename the asset `Stats.asset` to `RPG_Stats.asset`, but the internal name inside the Inspector is still "Stats", the filter `[SemanticKeyFilter("Stats")]` will continue to work.  
* If you rename the Domain using the **Rename** button in the custom Inspector, you **MUST** update your C\# attributes to match the new name.
